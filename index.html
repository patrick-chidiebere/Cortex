Privacy & capabilities
Your Groq key stays in the Cloudflare Worker; this HTML file does not contain it. Saved chats remain in this browser. The current Groq connection handles text; attached images are previewed but are not visually analysed by the current model. Cortex Live is an experimental browser speech loop, not a real-time audio model. Think Harder uses three model passes and a limited Wikipedia API evidence search; comprehensive web search needs a dedicated Worker-side search provider.
